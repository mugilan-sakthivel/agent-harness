System prompt vs. user prompt

The creator types one line about their video. What comes back depends on the instructions the agent sends above that line. In this episode you write the Strategist's system prompt and watch the same concept go from generic to on-brand.

Stage Brief You build the Strategist prompt About 20 min Checkpoint ep-03-system-prompt

Where this lives in the agent

The idea

2 min read

Every time an app asks a language model for something, it sends a short stack of messages. Two of them matter here.

The system prompt sits at the top. It holds the standing instructions: who the model is working for, the rules it has to follow, and what a good answer looks like. You write it once, and it goes out with every request.

The user prompt sits under it. It's the part that changes on every run. In Thumbnail Agent, it's the video concept the creator types into the box.

The model reads the whole stack from top to bottom, then answers the last message with everything above it in mind. Change what sits on top, and the same concept gets a very different answer.

You've seen this from the outside. The help chat in a food-delivery app and the assistant in a coding tool can run on the same kind of model, yet one talks about refunds and the other talks about code. Much of that difference comes from their system prompts. We can't read their prompts, so treat this as an analogy for how such apps are usually built.

Our Brief stage works the same way. Its system prompt, the Strategist, carries the channel's rules: four words at most, Tanglish, one emotion, and a fixed answer shape. Remove it and the model still answers. It just answers like a generic assistant.

System prompt
The rules that go out with every request. We write it once per stage.
User prompt
This run's request. The creator writes it: the video concept.

Check yourself

Question 1 · spot itThe creator types “I let 5 AI agents build the same app, one of them cheated” into the box. Which message is that?

The creator only ever writes the user prompt. The system prompt is ours: written once, sent with every run.

Question 2 · predictYou delete the line “Headline: 4 words max, never the video title” from the system prompt and run the same concept again. What will most likely happen?

Each request stands alone. Without the rule in the stack, the model falls back to its habit of long, title-like headlines. It only remembers earlier runs if you send them again.

Question 3 · place itWhich of these belongs in the system prompt?

The answer format applies to every run, so it lives in the system prompt. The topic and one-off requests change per run, so they go in the user prompt.

## Context
You have the Thumbnail Agent app from episode 2 (git tag ep-02-llm-call):
a Next.js page with a concept box that sends the creator's text to the
model and shows 5 headline ideas.
This step adds a system prompt. The concept stays the user prompt.

## Task
1. Create app/prompts/strategist.v1.md with the Strategist system prompt:
   - You are the Strategist for <channel name>, a <niche> channel.
   - Turn the video concept into a thumbnail brief.
   - Headline: 4 words max, never the video title.
   - Text language: <English | Tamil | Tanglish>.
   - One emotion for the face.
   - Answer in exactly 4 lines: Headline, Hook, Emotion, Key objects.
2. In app/api/brief/route.ts, read that file and call generateText from
   the Vercel AI SDK with system set to the file's contents and
   prompt set to the concept from the box, unchanged.
3. Add a "System prompt" on/off switch next to the Run button. When it
   is off, send the same concept with no system prompt.
4. Show the last two answers side by side, labelled "with" and "without".

## Constraints
- TypeScript, Next.js App Router, Vercel AI SDK. Model id stays in
  TEXT_MODEL in .env.
- The channel rules live only in strategist.v1.md. Don't copy them into
  the page or the route.
- Never paste the concept into the system prompt.
- Use the existing theme (design/tokens.css). No new UI library.

## Done when
- Switch on: the concept "I let 5 AI agents build the same app, one of
  them cheated" returns 4 lines, and the headline is 4 words or fewer.
- Switch off: the same concept returns longer, generic free text.
- Editing a rule in strategist.v1.md changes the next answer, with no
  code change.
- The request log shows the concept only in the user message.
